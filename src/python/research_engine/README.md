# QUANT RESEARCH ENGINE

Comprehensive Python algorithmic trading and simulation framework:
* `backtest/`: Discrete-event matching engine with spread friction and slippage modeling.
* `bot/`: Event-driven bot runtime, async order dispatchers, and risk managers.
* `data/`: Automated tick and bar harvesters via WebSocket and MT5 native API.
* `models/`: Statistical baselines, placebo models, and stochastic intensity estimators.
* `report/`: Performance reporting, risk metrics (Sharpe, Sortino, Calmar), and ruin theory calculations.
* `strategies/`: Abstract strategy interfaces and quantitative implementation archetypes.
